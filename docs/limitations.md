# Limitations
- Not piloted on a real prospecting program; v0.1.0 pre-release.
- The validator checks file contracts, not fit quality, source legitimacy, or consent.
- Web research requires user-authorized tools; import-first is the default and the only mode covered by the synthetic example.
- No contact discovery: unknown contact fields stay empty and score zero.
- Compliance (anti-spam, consent, data protection) is the user's responsibility.
- Python 3.10 verified; no agent-runtime compatibility claimed.
